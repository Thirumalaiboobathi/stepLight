# @steplight/core

The Steplight trace schema, hidden-instruction and data-exfiltration detectors, secret redaction, run storage, encryption, CI rules and OpenTelemetry mapping. It is the engine behind the [Steplight](https://github.com/steplight-dev/steplight) SDK, CLI and browser extension.

```bash
npm install @steplight/core
```

Most users want [`@steplight/sdk`](https://www.npmjs.com/package/@steplight/sdk) (record a Playwright agent) or [`@steplight/cli`](https://www.npmjs.com/package/@steplight/cli) (view, check and export runs). Everything runs locally; nothing is sent anywhere.

Documentation, security policy and threat model: https://github.com/steplight-dev/steplight. Apache-2.0.
