# @steplight/redteam

Harmless prompt-injection and data-exfiltration test pages for checking your own AI browser agent, from [Steplight](https://github.com/steplight-dev/steplight). Served on localhost only, with a scorecard of which attacks your agent fell for.

```bash
npm install @steplight/redteam
npx @steplight/cli redteam serve
```

Docs: https://github.com/steplight-dev/steplight. Apache-2.0.
